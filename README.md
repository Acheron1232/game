# Живі королівства

Фентезійна RTS про поселення (за `game_design_uk.docx` v1.1) у 3D-стилі Warcraft 3.

```bash
npm install
npm run dev        # http://localhost:5173   (?renderer=webgl — примусовий WebGL2, ?quick=1 — одразу в гру)
npm test           # симуляція: економіка, бот, хвилі, збереження, WASM-навігація, мережевий lockstep
npm run server     # продакшн-збірка + relay для гри по LAN (порт 8787)
npm run build      # wasm + typecheck + production bundle
```

## Технології
- **TypeScript** скрізь.
- **Three.js r186 `WebGPURenderer`** — WebGPU з автоматичним фолбеком на WebGL2; матеріали на TSL (колір команди, світіння, вітер, вода), bloom/віньєтка, тіні, день/ніч, пул точкових джерел світла.
- **WASM** (AssemblyScript, `wasm/nav.ts`) — A* + згладжування шляху; ідентичний TS-фолбек.
- Усі моделі процедурні (`src/r3d/characters.ts`, `buildings3d.ts`, `nature3d.ts`): один скінований меш на юніта, скелетні анімації кодом (`anim.ts`): спокій, ходьба/біг, рубання, удар списом, лук, закляття, рубка, кігті, удар, смерть, хода коня.
- Codex image generator — мальовані текстури землі та іконки (`tools/gen-assets.mjs`, `tools/process-assets.mjs`).

## Архітектура
```
src/sim/        авторитетна симуляція (20 тиків/с), чисті дані, команди
  systems/      behavior, movement, combat, economy, evil (ШІ зла), bot (ШІ гравця)
src/content/    усі визначення та числа балансу (дані)
src/r3d/        3D-рендер: engine, terrain, характери, будівлі, частинки, view
src/ui/         HUD, лобі, консоль, живий редактор
src/mods/api.ts публічне API `window.game`
```
Клієнти (гравець, бот) лише надсилають `Command`; симуляція їх перевіряє — готово до мережевого хоста.

## Кооператив по мережі
- Хост у лобі вводить код кімнати → «Створити». Друг відкриває ту саму адресу (у dev: `http://<IP-хоста>:5173`), вводить код → «Приєднатися», обирає героя й колір. Хост тисне «Почати гру».
- Для гри по LAN без dev-сервера: `npm run build && npm run server` → `http://<IP>:8787`.
- Схема: детермінований lockstep. Хост рахує світ і щотіку розсилає застосовані команди гравців; гості прораховують ту саму симуляцію, їхні команди перевіряє хост (гравець керує лише своєю фракцією). Контрольні суми кожні 2 с; при розбіжності — повна ресинхронізація. Боти й світове зло працюють однаково на всіх.

## Зміна гри під час сесії
- **Код**: правки в `src/content/*` і `src/sim/systems/*` підміняються на льоту (Vite HMR) без втрати стану. Будь-яка інша правка перезавантажує сторінку, а сесія автоматично відновлюється зі знімка.
- **Консоль** (`` ` ``): `game.patch('units.soldier.damage', 9)`, `game.give('all', 500)`, `game.spawn('skeleton')`, `game.time.speed(4)`, `game.evil.forceWave()`, `game.systems.add/replace(...)`, `game.help()`.
- **Живий редактор** (F2): усі числа героїв, юнітів, будівель, балансу.
- **Моди**: `game.mods.load('/mods/example-mod.js')` або перетягніть `.js` у вікно. Мод може патчити контент, додавати системи, команди, здібності, звуки, нових персонажів (`game.registerCharacter`).
- **Збереження**: F5 / F9, експорт у файл; перетягніть `.json`, щоб завантажити.
